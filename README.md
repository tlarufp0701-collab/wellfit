# WellFit — AI 기업 웰니스 플랫폼 MVP

기업의 건강·운동 복지를 임직원의 실제 신체활동과 연결하고, AI가 지속·중단·재참여 패턴을 분석해
다음 분기 복지 예산·프로그램·시설 의사결정을 돕는 B2B2C 웰니스 플랫폼의 클릭형 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev          # http://localhost:3000
# 또는 운영 빌드
npm run build && npm start
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` / `npm start` | 운영 빌드 / 실행 |
| `npm run typecheck` | TypeScript 검사 |
| `npm run lint` | ESLint |
| `npm run build:prototype` | 같은 화면을 단일 HTML(`dist/wellfit-prototype.html`)로 묶기 (해시 라우팅) |

휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 전체 화면으로 실행됩니다 (PWA manifest 포함, 시작 화면 `/employee`).

## 화면 (모두 실제 이동 가능)

**임직원 앱 (모바일 퍼스트, 하단 탭: 홈 / AI 코치 / 활동 / 시설 / 리워드)**

| 경로 | 내용 | 실제 동작 |
| --- | --- | --- |
| `/employee` | 홈 — 웰니스 점수, AI 오늘의 추천, KPI, 주간 목표, 다음 리워드 | 컨디션 체크인, 추천 이유, 다른 운동 추천, **지금 시작하기(타이머 → 기록 → 포인트)** |
| `/employee/ai-coach` | AI 코치 — 14개 입력 데이터, 추천·근거, 지속 가능성, 중단 위험, 위험요인 기여도, 대안 4종, 주간 플랜 | 체크인 수정 시 재계산, 대안 적용/되돌리기 → 위험도·플랜 재계산 |
| `/employee/activity` | 월간 캘린더, 4주/12주 지속률, 중단·재참여 횟수, 운동 종류, 시간대별 출석률, 시작→지속→중단→재시작 타임라인 | 월 이동, 날짜별 기록 보기 |
| `/employee/goals` | 개인 목표(주 N회, 3개월 습관), 회사 챌린지, 부서 익명 리더보드 | **목표 변경**, 챌린지 참여/취소 |
| `/employee/rewards` | 시작·지속·재참여·목표달성 보상 규칙, AI 추천 미션, 리워드 샵, 쿠폰함, 내역 | 미션 수락, **리워드 교환(쿠폰 코드 발급)**, 목표 리워드 지정 |
| `/employee/facilities` | 회사/집 주변 토글, 8개 카테고리, 지도, AI 적합도·추천 이유 | 필터, 즐겨찾기, 체험/1일 이용 예약, 시설에서 운동 시작 |
| `/employee/report` | 내 변화 리포트 — 웰니스 추이, 수면·스트레스, 체성분, 개인 패턴 | 4주/12주 전환 |

**기업 관리자 (PC 웹, 개인정보 없이 부서·조직 단위 익명 집계만)**

| 경로 | 내용 | 실제 동작 |
| --- | --- | --- |
| `/admin` | 10초 요약, KPI 7종(전기 대비), 부서별 참여율, 월별 지속률, Journey Funnel, 재참여 | **기간 필터(월/분기/반기/연간)**, **부서 필터** |
| `/admin/employees` | 부서별 표·그래프, 부서×연령 교차 히트맵 | 정렬, 지표 선택, **최소 공개 인원(5/10/20명) 미만 비공개 처리** |
| `/admin/ai-insights` | 이상 패턴 탐지, 중단 위험 그룹, 상관관계(r 자동 계산, 인과 아님 고지), 프리젠티즘, AI 액션 추천 | 근거 펼치기, 액션 상태(제안/검토 중/실행 예정/보류) → 경영진 리포트에 반영 |
| `/admin/wellness-report` | 추정 ROI·예상 절감 효과, 계산 근거, 효과 지표 | **회사 설정값 슬라이더로 ROI 실시간 재계산** |
| `/admin/facilities` | 시설별 이용자·이용률·12주 지속률·만족도·1인당 비용, AI 유지/확대/축소/교체 검토 | 담당자 최종 결정 → 다음 분기 예산 시뮬레이션 |
| `/admin/executive` | CEO/COO/CHRO용 1분 요약, AI 경영진 요약 | PDF 다운로드(인쇄 대화상자) |
| `/admin/pilot` | 8주/12주 파일럿 — 80명 Baseline/W4/W8/W12 비교, 성공 기준, HR 피드백 설문 | 8주/12주 전환, 설문 제출·수정 |

변경한 목표·운동 기록·포인트·쿠폰·예약·체크인·관리자 결정·ROI 설정·파일럿 응답은 `localStorage`(`wellfit.v1`)에 저장되어 새로고침 후에도 유지됩니다. 사이드바의 "초기화"로 데모 데이터를 되돌릴 수 있습니다.

## 구조

```
app/                    Next.js App Router 라우트 (얇은 래퍼)
views/employee|admin/   화면 컴포넌트
components/             UI 키트, 셸(하단 탭·사이드바), 차트 공통
lib/data/               현실적인 mock 데이터 (개인 기록, 시설, 리워드, 부서·팀·파일럿 집계)
lib/ai/coach.ts         개인 AI 코치 엔진: 활동 지표, 웰니스 점수, 중단 위험, 추천, 대안, 주간 플랜
lib/ai/insights.ts      기업 AI 엔진: 이상 탐지, 상관계수, 액션 추천, ROI, 시설 조정, 경영진 요약
lib/ai/facility.ts      시설 AI 적합도
lib/store.tsx           상태 + localStorage 영속화
lib/nav.tsx             라우팅 추상화 (Next 라우터 / 해시 라우터 교체 가능)
prototype/              단일 HTML 프로토타입 엔트리
```

### 실제 AI 연결 방법
`lib/ai/*`의 함수는 입력(익명 집계·행동 데이터) → 출력(추천·예측·인사이트) 형태의 순수 함수입니다.
같은 시그니처를 유지한 채 내부를 모델 API 호출(예: Next.js Route Handler `/api/coach`)로 바꾸면 UI는 수정 없이 동작합니다.

### Mock AI 로직 요약
- **웰니스 점수** = 활동 35 + 수면 22 + 스트레스 20 + 컨디션 19 + 꾸준함 4
- **중단 위험(14일)** = 운동빈도 감소 · 계획 대비 결석 · 평일 저녁 결석 · 과거 중단 직전 패턴 유사도 · 수면 감소 · 스트레스 · 목표 미달의 가중합 − 적용한 대안 효과
- **추천** = 시간대별 실제 출석률, 선호 운동, 오늘 컨디션, 통증 부위, 혼자/그룹 성향, 요일로 후보 점수화
- **기업 인사이트** = 전분기 대비 ±12% 이상 변화, 3주 연속 상승, 연령대 격차 15% 이상 자동 탐지 / 팀 단위 피어슨 r 계산
- **ROI** = (추정 편익 − 총 비용) ÷ 총 비용 × 100, 편익 = 병가 감소 + 프리젠티즘 개선 + 이직 위험 감소 + 복지 미사용 감소

## 원칙
- 기업 관리자에게 개인 건강정보·이름을 노출하지 않음, 최소 그룹 인원 미만 비공개
- AI 수치는 "AI 추정 · 행동 패턴 기반"으로 표기, 의료 진단 아님
- 상관관계를 인과관계로 단정하지 않음, ROI는 "추정 ROI / 예상 절감 효과"로 표기

## MVP 범위 밖 (상용화 시 필요)
로그인·SSO와 역할 권한, 백엔드 DB와 API, 실제 AI 모델 연동, 웨어러블·인바디·시설 QR 연동, 결제·정산, 푸시 알림, 개인정보 처리방침과 동의 관리, 의료 진단·보험·EMR 연동(제외 대상).

## Render 배포

저장소 루트의 `render.yaml`(Blueprint)로 설정됩니다.

1. Render 대시보드 → **New +** → **Blueprint** → 이 GitHub 저장소 선택 → **Apply**
2. 빌드 `npm ci && npm run build`, 실행 `npm start` (Render가 주는 `PORT`를 사용)
3. 이후 `main` 브랜치에 push하면 자동 재배포됩니다.

무료 플랜은 15분간 접속이 없으면 잠들고, 다음 접속 때 30초~1분 정도 깨어나는 시간이 걸립니다.
